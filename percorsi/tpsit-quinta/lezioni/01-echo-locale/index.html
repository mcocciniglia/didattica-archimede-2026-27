Il primo dialogo client-server

Un messaggio parte, il server lo riceve e lo restituisce.

Durata: 2 ore Strumenti: Python e due terminali Prerequisito: Lezione 0 Rete: solo questo computer

Da dove partiamo

Richiesta e risposta

Nella Lezione 0 abbiamo seguito il percorso di un messaggio: il client invia una richiesta, il server la riceve e prepara una risposta.

Oggi vedremo questo scambio sul nostro computer. Non dobbiamo ancora memorizzare tutte le istruzioni: ci interessa riconoscere le parti e osservare che cosa accade.

Una socket è il punto software attraverso il quale un programma invia o riceve dati; per ora ci basta riconoscerla come il collegamento usato dai due programmi.

Il nostro esperimento

Un server echo su localhost

i
Facciamo partire un server sul nostro computer, gli inviamo un messaggio con un client e osserviamo la risposta.

Stesso computer

Client e server useranno entrambi 127.0.0.1, cioè il computer sul quale stiamo lavorando. Questo indirizzo è chiamato anche localhost.

Stessa porta

Il server resterà in ascolto sulla porta 50000. Il client userà questo numero per individuare il servizio al quale collegarsi.

Un messaggio

Il server echo riceverà un solo messaggio e lo restituirà al client. Al termine, entrambi i programmi si chiuderanno.

Controlliamo l’ambiente

Python, cartella e due terminali

    Crea o apri una cartella di lavoro e salva al suo interno i due file della lezione senza rinominarli.

  3. Apri due terminali.

    In entrambi esegui:

Scarica server_echo.py Scarica client_echo.py

server_echo.py

import socket


HOST = "127.0.0.1"
PORT = 50000


def main():
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as server_socket:
        server_socket.bind((HOST, PORT))
        server_socket.listen(1)
        print(f"Server in ascolto su {HOST}:{PORT}")
        print("In attesa di un messaggio...")

        connection, address = server_socket.accept()
        with connection:
            print(f"Client collegato da {address[0]}")
            data = connection.recv(1024)
            message = data.decode("utf-8")
            print(f"Messaggio ricevuto: {message}")

            response = message
            connection.sendall(response.encode("utf-8"))
            print(f"Risposta inviata: {response}")

    print("Server terminato.")


if __name__ == "__main__":
    main()
  • bind collega il server all’indirizzo e alla porta scelti.
  • listen e accept preparano e attendono il collegamento del client.
  • recv riceve i dati; sendall invia la risposta.
  • encode e decode permettono di usare testo UTF-8.

client_echo.py

import socket


HOST = "127.0.0.1"
PORT = 50000


def main():
    message = input("Messaggio da inviare: ").strip()
    if not message:
        print("Nessun messaggio da inviare.")
        return

    try:
        with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as client_socket:
            print(f"Connessione al server {HOST}:{PORT}...")
            client_socket.connect((HOST, PORT))
            client_socket.sendall(message.encode("utf-8"))
            print(f"Messaggio inviato: {message}")

            data = client_socket.recv(1024)
    except ConnectionRefusedError:
        raise SystemExit(
            "Connessione rifiutata: avvia prima il server e riprova."
        )

    response = data.decode("utf-8")
    print(f"Risposta ricevuta: {response}")


if __name__ == "__main__":
    main()
  • connect chiede di collegarsi al server.
  • Il client prima invia il messaggio e poi attende la risposta.
  • Se il server non è attivo, il programma mostra un messaggio comprensibile.

Avvio

Prima il server, poi il client

  1. Primo terminale: avvia il server.
    py server_echo.py

    Deve comparire il messaggio In attesa di un messaggio....

  2. Secondo terminale: avvia il client.
    py client_echo.py

    Se stai usando il comando alternativo, sostituisci py con python in entrambi i terminali.

  3. Scrivi un messaggio.

    Inserisci una frase breve e premi Invio.

  4. Confronta i terminali.

    Nel terminale del server osserva il messaggio ricevuto e la risposta inviata. Nel terminale del client osserva la risposta ricevuta.

Che cosa è successo

Seguiamo il viaggio del messaggio

Client → messaggio → server → risposta → client

  1. Il client apre il collegamento e invia il testo.
  2. Il server riceve e decodifica il messaggio.
  3. Il server usa il testo ricevuto per costruire la risposta echo.
  4. Il server invia la risposta e il client la riceve.

Inviare e ricevere sono azioni distinte: ciò che un programma invia deve essere ricevuto dall’altro lato.

Proviamo a modificarlo

Piccole variazioni, nuovo risultato

  1. Riavvia il server e prova un messaggio diverso.
  2. Nel server, sostituisci response = message con:
response = f"Ricevuto: {message}"

Riavvia entrambi i programmi e controlla come cambia la risposta.

Variante facoltativa — risposta in maiuscolo

Prova a costruire la risposta con message.upper(), poi verifica che il client riceva il testo trasformato.

Un errore utile

Che cosa accade senza server?

  1. Controlla che il server sia chiuso.

    Dopo uno scambio completo il nostro server termina da solo.

  2. Avvia soltanto il client.
    py client_echo.py
  3. Leggi il messaggio.

    Dovrebbe comparire: Connessione rifiutata: avvia prima il server e riprova.

Il client conosce indirizzo e porta, ma in quel momento nessun server è in ascolto. Per questo la comunicazione non può iniziare.

Verifica finale

Tre domande

  1. Perché il server deve essere avviato prima del client?
  2. Che cosa rappresenta 127.0.0.1?
  3. In quale punto del programma nasce la risposta?

In sintesi

Cinque idee da ricordare

  • Client e server sono due programmi con compiti diversi.
  • 127.0.0.1 indica il computer sul quale stiamo lavorando.
  • Indirizzo e porta devono coincidere nei due programmi.
  • Il server deve essere in ascolto prima che il client si colleghi.
  • Un server echo restituisce il messaggio che ha ricevuto.
