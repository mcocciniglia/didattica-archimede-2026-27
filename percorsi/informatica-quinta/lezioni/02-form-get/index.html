Lezione 2 · M0 · Informatica · Classi quinte

Dal browser al server: form e metodo GET

Inviare dati a PHP e generare una risposta dinamica.

Durata: circa 2 ore Strumenti: editor, terminale e browser Prerequisito: Lezione 1 Prodotto: form e risposta PHP

Ripasso iniziale

Il server produce la pagina

Nella Lezione 1 il browser era il client. Il comando php -S localhost:8000 avviava un server HTTP locale, raggiungibile attraverso la porta 8000.

File HTML statico

Il browser riceve il contenuto scritto nel file e lo rappresenta.

Pagina PHP dinamica

Il server esegue PHP e costruisce la risposta HTML prima di inviarla al browser.

Richiesta e risposta

Il browser invia una richiesta HTTP; il server restituisce una risposta HTTP.

?

Domanda guida

Finora il server produceva una pagina. Come possiamo permettere all’utente di inviare un dato al server?

Al termine

Il percorso che saprai ricostruire

✓

input HTML → richiesta HTTP → parametro GET → PHP → risposta HTML → browser

Preparare

Creare un form con campi associati a etichette e scegliere la pagina di destinazione.

Inviare

Riconoscere nell’URL i parametri trasmessi con il metodo GET.

Rispondere

Leggere un parametro con PHP e usarlo per generare una pagina.

i

Parole operative

Tre idee nuove

  • form: una parte della pagina che raccoglie dati inseriti dall’utente;
  • parametro GET: un dato scritto nella richiesta e visibile nell’URL;
  • $_GET: la struttura PHP dalla quale leggiamo i parametri ricevuti con GET.
⏱

Percorso indicativo

Due ore, con spazio per provare

Circa 15 minuti di ripasso, 20 minuti sul form, 20 minuti su PHP e $_GET, 10 minuti per osservare l’URL, 40 minuti di laboratorio e 15 minuti per confronto, correzione e isset(). I tempi sono orientativi: possiamo fermarci dove serve.

Primo passaggio

Un form HTML invia il nome

Crea una nuova cartella di lavoro, aprila nell’editor e aggiungi un file chiamato index.html:

<!DOCTYPE html>
<html lang="it">
<head>
    <meta charset="UTF-8">
    <title>Il mio primo form</title>
</head>
<body>

<h1>Presentati</h1>

<form action="saluto.php" method="get">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome">

    <button type="submit">Invia</button>
</form>

</body>
</html>

form

Raggruppa i controlli che raccolgono i dati e stabilisce come inviarli.

action="saluto.php"

Indica la pagina del server alla quale il browser invierà i dati.

method="get"

Dice al browser di inviare i dati come parametri GET, visibili nell’URL.

input

Crea il campo nel quale l’utente può scrivere il proprio nome.

!

La parte decisiva

name="nome"

L’attributo name stabilisce il nome del parametro inviato al server. Senza name, il testo scritto nel campo non viene inviato come parametro del form.

Secondo passaggio

PHP riceve il parametro

Nella stessa cartella crea saluto.php:

<!DOCTYPE html>
<html lang="it">
<head>
    <meta charset="UTF-8">
    <title>Saluto</title>
</head>
<body>

<?php
$nome = $_GET["nome"];
echo "<h1>Ciao $nome!</h1>";
?>

</body>
</html>
  • $_GET contiene i parametri ricevuti con il metodo GET;
  • $_GET["nome"] legge il parametro che si chiama nome;
  • $nome è la variabile nella quale conserviamo il valore ricevuto;
  • echo inserisce il saluto nella risposta HTML.
!
Esempio volutamente minimo

Usiamo questo codice soltanto nel laboratorio locale per osservare il percorso dei dati. Non è ancora una soluzione pronta per un sito pubblico: validazione e sicurezza verranno affrontate più avanti.

  1. Avvia il server nella cartella.
    php -S localhost:8000
  2. Apri il form.

    Visita http://localhost:8000/index.html.

  3. Invia un nome.

    Scrivi Marco e premi il pulsante Invia.

  4. Osserva il risultato.

    Il server esegue saluto.php e il browser mostra il saluto generato.

Esperimento importante

Leggiamo la richiesta nell’URL

Dopo l’invio, nella barra degli indirizzi compare qualcosa di simile:

http://localhost:8000/saluto.php?nome=Marco

Il form ha costruito una richiesta HTTP diretta a saluto.php e vi ha aggiunto il dato inserito:

/saluto.php

È la risorsa richiesta al server.

?

Separa il percorso della pagina dai parametri della richiesta.

nome

È il nome del parametro, scelto con name="nome".

=Marco

È il valore che il browser ha inviato per quel parametro.

i

Più parametri GET

Un solo URL, più valori

scheda.php?nome=Mario&cognome=Rossi&eta=18&classe=5F

? introduce la query string; = associa il nome del parametro al suo valore; & separa un parametro dal successivo.

✎

Prova diretta

Modifica manualmente il parametro

Nella barra degli indirizzi sostituisci la parte finale con saluto.php?nome=Anna e premi Invio. Il server riceve il nuovo valore e produce una risposta diversa.

Modello client-server

Il form genera una richiesta HTTP

Browser
   ↓
GET /saluto.php?nome=Marco
   ↓
Server PHP
   ↓
$_GET["nome"]
   ↓
HTML generato
   ↓
Browser

Il form non esegue PHP. Il browser legge il form, costruisce la richiesta GET e la invia al server. Solo il server esegue PHP; il browser riceve la risposta HTML già generata.

Esercitazione guidata

Laboratorio — La scheda dello studente

Prodotto atteso: un form che invia quattro parametri con GET e una pagina scheda.php che li usa per generare una scheda.

  1. Prepara il form.

    Crea una pagina che chieda nome, cognome, età e classe.

  2. Imposta la destinazione.

    Il form deve usare action="scheda.php" e method="get".

  3. Scegli i nomi dei parametri.

    Usa name="nome", name="cognome", name="eta" e name="classe".

  4. Costruisci la risposta.

    In scheda.php leggi i quattro parametri e produci una pagina con titolo Scheda dello studente.

  5. Controlla URL e risultato.

    Verifica che i quattro parametri compaiano nell’URL e che la pagina mostri i valori inviati.

Un possibile form di partenza

<form action="scheda.php" method="get">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome"><br>

    <label for="cognome">Cognome:</label>
    <input type="text" id="cognome" name="cognome"><br>

    <label for="eta">Età:</label>
    <input type="number" id="eta" name="eta"><br>

    <label for="classe">Classe:</label>
    <input type="text" id="classe" name="classe"><br>

    <button type="submit">Crea scheda</button>
</form>

La pagina finale dovrebbe mostrare una struttura simile:

Scheda dello studente

Nome: Mario
Cognome: Rossi
Età: 18
Classe: 5F

L’attività è completa quando:

  • il form contiene quattro etichette associate ai rispettivi campi;
  • ogni campo ha un attributo name riconoscibile;
  • l’invio apre scheda.php;
  • nell’URL compaiono quattro parametri;
  • la risposta HTML mostra i quattro valori ricevuti.
Aiuto 1 — individua il primo parametro

Inizia soltanto dal nome: assegna $_GET["nome"] a una variabile e mostrala con echo. Quando funziona, aggiungi gli altri campi uno alla volta.

Aiuto 2 — mantieni gli stessi nomi

Il testo scritto in name="..." nel form deve coincidere con il testo usato tra parentesi quadre in $_GET["..."].

Un caso da gestire

Se il parametro non è presente

Se apriamo direttamente saluto.php senza aggiungere ?nome=..., il parametro nome non esiste. Possiamo controllarlo prima di leggerlo:

<?php
if (isset($_GET["nome"])) {
    $nome = $_GET["nome"];
    echo "<h1>Ciao $nome!</h1>";
}
?>
isset()

Controlla se un valore è presente. Qui permette di eseguire il saluto soltanto quando il parametro nome è stato ricevuto.

Per ora ci fermiamo a questo controllo essenziale. Validazione, filtri e sicurezza verranno affrontati nelle lezioni successive.

Soluzione possibile — scheda.php

Apri questo esempio soltanto dopo aver provato a costruire la pagina in autonomia.

<!DOCTYPE html>
<html lang="it">
<head>
    <meta charset="UTF-8">
    <title>Scheda dello studente</title>
</head>
<body>

<?php
if (isset(
    $_GET["nome"],
    $_GET["cognome"],
    $_GET["eta"],
    $_GET["classe"]
)) {
    $nome = $_GET["nome"];
    $cognome = $_GET["cognome"];
    $eta = $_GET["eta"];
    $classe = $_GET["classe"];

    echo "<h1>Scheda dello studente</h1>";
    echo "<p>Nome: $nome</p>";
    echo "<p>Cognome: $cognome</p>";
    echo "<p>Età: $eta</p>";
    echo "<p>Classe: $classe</p>";
}
?>

</body>
</html>

Verifica rapida

Tre domande

  1. Quale attributo del form stabilisce il nome del parametro inviato?
  2. Da quali parti è composto ?nome=Marco?
  3. Chi esegue PHP e che cosa riceve il browser?
Controlla le risposte
  1. L’attributo name del campo.
  2. Dal separatore ?, dal nome del parametro nome, dal segno = e dal valore Marco.
  3. PHP viene eseguito sul server; il browser riceve la risposta HTML generata.

A fine lezione

Dovresti saper…

  • creare un form HTML;
  • spiegare gli attributi action, method e name;
  • inviare parametri con GET;
  • riconoscere i parametri nell’URL;
  • leggere un parametro con $_GET;
  • descrivere il percorso browser → server → browser.
