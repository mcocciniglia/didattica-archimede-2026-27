# File iniziali — Lezione 6 di Informatica quinta

1. Scarica `attivita.php.txt` ed `elabora.php.txt` in una cartella nuova.
2. Mostra le estensioni dei file e rinominali `attivita.php` ed `elabora.php`: togli solo il suffisso `.txt`.
3. Apri il terminale in quella cartella. Verifica `php -v` (PHP 8.x), poi avvia `php -S localhost:8000`.
4. Apri `http://localhost:8000/attivita.php` nel browser. Scegli un’attività.
5. Completa i tre TODO di `elabora.php` seguendo la lezione. Lo scheletro rifiuta ogni invio finché i controlli provvisori non vengono sostituiti.
6. Usa solo dati inventati, per esempio `Studente di prova`, `prova@example.com`, `18`. Annota input, previsione ed esito dei test.

Il sito GitHub Pages distribuisce il testo dei sorgenti e la lezione: non esegue PHP. Il mini-progetto funziona sul server PHP locale. Non usa database, file di salvataggio, cookie o sessioni; il riepilogo non registra un’iscrizione reale.

Per concludere: conserva i due file completati e la tabella delle prove. Consegna nell’ambiente riservato indicato dal docente; non pubblicare dati personali nei repository.
