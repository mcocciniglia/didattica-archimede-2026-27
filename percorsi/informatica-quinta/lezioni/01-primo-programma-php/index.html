Dal file statico alla pagina dinamica: il primo programma PHP

Avviamo un server locale, eseguiamo poche istruzioni e osserviamo che cosa riceve davvero il browser.

Durata: circa 1 ora Strumenti: editor, terminale e browser Prerequisiti: HTML e modello client-server Prodotto: due pagine PHP funzionanti

Richiamo iniziale

Dal browser al server e ritorno

Hai già incontrato il linguaggio PHP: Hypertext Preprocessor (PHP), il linguaggio HyperText Markup Language (HTML) e il protocollo Hypertext Transfer Protocol (HTTP). Oggi ci interessa soltanto rivederli in azione.

Pagina HTML

Il browser legge il contenuto scritto nel file e lo rappresenta.

Pagina PHP

Il server HTTP riceve la richiesta; l’interprete PHP esegue le istruzioni e il server invia al browser l’HTML prodotto.

i

Ricorda

Il passaggio centrale

PHP viene eseguito lato server dall’interprete PHP. Il browser riceve soltanto il risultato dell’esecuzione.

Al termine

Che cosa saprai fare

Preparare

Creare la cartella di lavoro, il file index.php e avviare il server locale.

Eseguire

Aprire una pagina PHP da http://localhost:8000 e modificarne il risultato.

Osservare

Confrontare il programma sul server con il codice HTML ricevuto dal browser.

i

Parole operative

Tre termini utili oggi

  • localhost: indica il computer sul quale stai lavorando;
  • porta 8000: è il numero usato dal browser per raggiungere questo servizio locale;
  • output: è il risultato prodotto dal programma.

Per ora basta questo significato pratico: rete e porte saranno approfondite in un altro percorso.

Preparazione

Cartella, file e server locale

  1. Crea la cartella.

    Prepara una cartella chiamata lezione1-php e aprila nel tuo editor.

  2. Crea il file.

    All’interno della cartella crea index.php. Il nome index indica la pagina che il server cerca quando nell’indirizzo non specifichiamo un file.

  3. Apri il terminale nella cartella.

    Esegui dir e verifica che nell’elenco compaia index.php.

    dir
  4. Avvia il server HTTP integrato di PHP.

    Lascia aperto questo terminale mentre lavori.

    php -S localhost:8000
    !

    Se php non viene riconosciuto

    Su alcuni PC Windows il comando php non è disponibile nel PATH. Se usi PHP tramite XAMPP, prova:

    C:\xampp\php\php.exe -S localhost:8000
  5. Apri la pagina.

    Nel browser visita:

    http://localhost:8000
!

Attenzione

Non aprire il file con un doppio clic

Un indirizzo che inizia con file:// apre direttamente un file e non esegue PHP. Usa l’indirizzo http://localhost:8000. Per arrestare il server torna nel terminale e premi Ctrl+C.

Primo risultato

Un programma minimo

Inserisci questo codice in index.php, salva e aggiorna il browser:

<?php
echo "Ciao mondo!";
?>
✓

Osserva

Che cosa compare?

Nel browser deve apparire Ciao mondo!. Se vedi il codice PHP oppure il download del file, controlla di avere usato l’indirizzo HTTP e che il server sia ancora attivo.

HTML e PHP nella stessa pagina

Ora sostituisci il contenuto del file con questa pagina completa:

<!doctype html>
<html lang="it">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>La mia prima pagina PHP</title>
</head>
<body>
  <h1>La mia prima pagina PHP</h1>

  <?php
  echo "<p>Ciao dal server!</p>";
  ?>
</body>
</html>

Il codice HTML descrive la pagina. Le istruzioni comprese tra <?php e ?> vengono invece eseguite dal server prima dell’invio al browser.

Un dato che può cambiare

Le prime variabili

Una variabile è un nome al quale assegniamo un valore che il programma può usare. Modifica il blocco PHP in questo modo:

<?php
$nome = "Giulia";
$classe = "5F";

echo "<p>Ciao $nome!</p>";
echo "<p>Frequenti la classe $classe.</p>";
?>
  • $ identifica una variabile PHP;
  • = assegna un valore;
  • echo produce un output;
  • l’output entra nell’HTML inviato al browser.
✎

Prova tu

Personalizza il risultato

Crea le variabili $nome, $cognome, $classe e $anno. Usale per ottenere un risultato simile a questo:

Benvenuta Giulia Bianchi

Classe: 5F
Anno scolastico: 2026/2027
  • almeno un elemento <h1>;
  • almeno due elementi <p>;
  • almeno tre variabili PHP;
  • almeno due istruzioni echo.

Esperimento importante

Dove è finito il codice PHP?

  1. Lascia aperta la pagina funzionante.

    Controlla che nel browser compaiano i valori delle variabili.

  2. Visualizza il sorgente ricevuto.

    Usa il comando del browser “Visualizza sorgente pagina”; in molti browser puoi premere Ctrl+U.

  3. Cerca il codice PHP.

    Trovi $nome, echo oppure i delimitatori <?php ... ?>?

  4. Confronta.

    Nel sorgente ricevuto dovresti vedere HTML e i valori prodotti, ma non le istruzioni PHP originali.

✓

Conclusione

Il lavoro lato server è già concluso

Il codice è stato eseguito dall’interprete PHP lato server prima che la pagina fosse inviata. Il browser ha ricevuto il risultato in HTML.

Se hai terminato

Crea presentazione.php

Se hai completato le attività precedenti, prova a creare una seconda pagina PHP in autonomia.

Crea nella stessa cartella una piccola pagina di presentazione. Definisci almeno le variabili $nome, $classe e $materia, quindi usale per generare contenuto HTML.

La pagina è completa quando:

  • si apre da http://localhost:8000/presentazione.php;
  • contiene una struttura HTML valida con titolo e intestazione;
  • mostra i valori di almeno tre variabili;
  • usa almeno due istruzioni echo;
  • nel sorgente ricevuto non compare il codice PHP.
Aiuto 1 — da dove partire

Copia la struttura HTML di index.php, cambia il titolo e prepara le variabili all’inizio del blocco PHP.

Aiuto 2 — una possibile soluzione
<!doctype html>
<html lang="it">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Presentazione</title>
</head>
<body>
  <?php
  $nome = "Giulia";
  $classe = "5F";
  $materia = "Informatica";

  echo "<h1>Benvenuta, $nome!</h1>";
  echo "<p>Classe: $classe</p>";
  echo "<p>Materia: $materia</p>";
  ?>
</body>
</html>

Verifica rapida

Quattro domande

  1. Chi esegue il codice PHP?
  2. Che cosa riceve normalmente il browser dopo l’esecuzione di uno script PHP?
  3. A che cosa serve echo?
  4. Qual è la differenza essenziale tra aprire un file PHP tramite file:// e tramite http://localhost:8000?
Controlla le risposte
  1. L’interprete PHP, lato server.
  2. Il risultato prodotto dal programma, normalmente codice HTML.
  3. Produce un output che può entrare nella pagina restituita.
  4. file:// apre direttamente il file; l’indirizzo HTTP invia la richiesta al server, che affida il codice all’interprete PHP prima di rispondere.

In breve

Il modello da ricordare

Browser → richiesta HTTP → server → esecuzione PHP → risposta HTML → browser

Oggi bastano questo percorso, poche variabili e echo. Gli altri costrutti del linguaggio arriveranno nelle lezioni successive.
