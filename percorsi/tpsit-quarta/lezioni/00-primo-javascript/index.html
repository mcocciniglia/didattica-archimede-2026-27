Dalla pagina statica al primo JavaScript

HTML ci permette di costruire una pagina. Ma come facciamo a farle fare qualcosa?

TPSIT · Classe quarta Strumenti: browser ed editor di codice Prerequisito: una semplice pagina HTML Prodotto: una pagina che reagisce a un click

10 minuti · Partiamo da una domanda

Come può una pagina reagire?

Una pagina può mostrare un testo e un pulsante. Oggi faremo in modo che il testo cambi quando l’utente preme quel pulsante.

HTML       → struttura e contenuto
CSS        → aspetto
JavaScript → comportamento

JavaScript è un linguaggio di programmazione. In questo primo percorso lo useremo direttamente nel browser per rendere interattive le pagine Web.

Può modificare un testo, controllare un dato inserito dall’utente, aprire un menu o aggiornare un contenuto senza riscrivere manualmente il documento HTML.

Al termine

Che cosa saprai fare

Eseguire

Aprire la console del browser e provare semplici istruzioni JavaScript.

Collegare

Usare un file script.js separato e verificare che venga caricato dalla pagina.

Modificare

Individuare un elemento HTML e cambiarne il testo con JavaScript.

Far reagire

Fare in modo che un click sul pulsante produca un cambiamento visibile.

15 minuti · Esperimento 2

Diamo un nome ai valori

Esegui il blocco una volta e osserva prima i valori iniziali, poi quelli riassegnati:

let nome = "Anna";
let eta = 16;

console.log(nome);
console.log(eta);

nome = "Luca";
eta = 17;

console.log(nome);
console.log(eta);

In let nome = "Anna";, nome è il nome della variabile, il segno = assegna il valore e "Anna" è una stringa, cioè un testo. 16, senza virgolette, è un numero.

let dichiara la variabile. Per cambiarne successivamente il valore non dobbiamo scrivere nuovamente let.

Variabile

È un nome associato a un valore che il programma può usare e, quando serve, riassegnare.

let a = 5;
let b = 3;

console.log(a + b);
?

Prima di eseguire

Numero o testo?

Prevedi il risultato. Poi scrivi a = "5";, senza ripetere let, esegui di nuovo console.log(a + b); e osserva che cosa cambia.

Possiamo anche dichiarare un nome che non vogliamo riassegnare:

const scuola = "Archimede";

Usiamo const quando non vogliamo assegnare in seguito un nuovo valore a quel nome.

Mini-esercizio

Crea le tre dichiarazioni seguenti con i tuoi valori e mostrale nella console:

let nomeStudente = "Mario";
let annoNascita = 2010;
const nomeScuola = "Archimede";

console.log(nomeStudente);
console.log(annoNascita);
console.log(nomeScuola);

15 minuti · Esperimento 3

Dalla console a un vero file

Crea una cartella e due file con questa struttura:

primo-js/
├── index.html
└── script.js

Inserisci in index.html:

<!doctype html>
<html lang="it">
<head>
    <meta charset="utf-8">
    <title>Il mio primo JavaScript</title>
    <script src="script.js" defer></script>
</head>
<body>

    <h1>La mia prima pagina con JavaScript</h1>
    <p>Apri la console del browser.</p>

</body>
</html>

Inserisci in script.js:

console.log("JavaScript è stato caricato!");
  1. Apri index.html nel browser.

    La pagina mostra titolo e paragrafo.

  2. Apri la console.

    Controlla dove compare il messaggio scritto nel file JavaScript.

  3. Modifica il messaggio.

    Salva script.js, ricarica la pagina e verifica il nuovo risultato.

Nell’elemento <script>, l’attributo src indica il file JavaScript. defer permette al browser di eseguire lo script dopo aver analizzato il documento HTML.

✓

Checkpoint

Il collegamento funziona

La prova è superata quando ogni modifica salvata in script.js compare nella console dopo il ricaricamento.

20 minuti · Esperimento 4

JavaScript modifica la pagina

Sostituisci il contenuto del <body> con:

<h1 id="titolo">Pagina statica</h1>

<p id="messaggio">
    Questo testo è scritto nell'HTML.
</p>

Ora sostituisci il contenuto di script.js con:

const titolo = document.getElementById("titolo");

titolo.textContent = "La pagina è stata modificata da JavaScript";
?

Prima di eseguire

Secondo te, cosa cambierà?

Indica una parte precisa della pagina, poi salva e ricarica.

Document Object Model (DOM)

Il DOM è la rappresentazione della pagina HTML che JavaScript può leggere e modificare.

✓

Osserva

Quale testo vedi adesso?

Il browser non mostra più esattamente il titolo scritto nel file HTML: JavaScript lo ha modificato dopo il caricamento.

Aggiungi in fondo a script.js:

const messaggio = document.getElementById("messaggio");

messaggio.textContent = "Anche questo testo è stato modificato.";

getElementById() individua l’elemento che possiede l’id indicato. textContent permette di leggerne o cambiarne il testo.

20 minuti · Esperimento 5

La pagina reagisce all’utente

Aggiungi nel <body>:

<button id="pulsante">Cambia messaggio</button>

<p id="risultato">
    Non hai ancora premuto il pulsante.
</p>

Aggiungi in fondo a script.js:

const pulsante = document.getElementById("pulsante");
const risultato = document.getElementById("risultato");

pulsante.addEventListener("click", function () {
    risultato.textContent = "Hai premuto il pulsante!";
});
Evento

È qualcosa che accade nella pagina. In questo esperimento l’evento è il click dell’utente.

addEventListener indica al browser che cosa deve fare quando avviene un evento. Per ora ci basta sapere che il codice tra le parentesi graffe verrà eseguito quando l’utente farà click.

?

Prima di eseguire

Quando cambierà il paragrafo?

Prevedi che cosa vedrai subito dopo il ricaricamento e che cosa vedrai soltanto dopo il click.

✓

Osserva

La pagina ora è interattiva

Premi il pulsante più volte: il cambiamento avviene in risposta a una tua azione.

20 minuti · Laboratorio individuale

La mia prima pagina dinamica

Consegna: crea una piccola pagina con un titolo, un paragrafo e almeno un pulsante. Usa un file HTML e un file JavaScript separato. Quando l’utente preme il pulsante, JavaScript deve modificare il testo del paragrafo.

Prima:
Oggi stiamo imparando JavaScript.

[ Cambia messaggio ]

Dopo:
La pagina ha reagito al mio click!

Scegli liberamente i due messaggi. Procedi un passo alla volta e ricarica la pagina dopo ogni modifica.

Suggerimento 1 — individua il paragrafo
document.getElementById(...)

Controlla che l’id usato tra parentesi sia presente nel paragrafo HTML.

Suggerimento 2 — reagisci al click
addEventListener("click", ...)

Nel codice eseguito al click, assegna il nuovo testo a textContent.

✓

Criteri di completamento

Il risultato minimo è pronto quando…

  • i due file sono salvati nella stessa cartella;
  • la console conferma che JavaScript è caricato senza errori;
  • il testo cambia soltanto quando premi il pulsante;
  • sai indicare l’elemento HTML modificato dal codice.

Facoltativa · Per chi termina prima

Aggiungi il pulsante “Ripristina”

Aggiungi un secondo pulsante che riporti il paragrafo al testo originale. Non servono concetti nuovi: assegna un id al nuovo pulsante e riusa gli stessi passaggi già provati.
